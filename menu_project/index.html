Динамічне меню на JavaScript

Наведіть курсор миші на пункти «Послуги», «Портфоліо» або «Про нас», щоб відкрити підменю. Меню з’являється плавно і закривається після відведення курсора.

Статус: меню закрите

Як це працює

Події mouseenter та mouseleave відстежують наведення. Клас open додається до пункту меню, а aria-expanded оновлюється для доступності.

Адаптивність

На вузьких екранах з’являється кнопка-гамбургер. Підменю відкриваються кліком, щоб зручно користуватися на сенсорних пристроях.

Без бібліотек

Уся логіка написана на чистому JavaScript. Стилі - у звичайному CSS без фреймворків. Сторінка працює локально через file://.

Область демонстрації

Оберіть пункт підменю - тут з’явиться повідомлення.
